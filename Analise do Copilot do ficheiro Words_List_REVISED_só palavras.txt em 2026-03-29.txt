## Python Script for Frequency and N-gram Computation
```python
import pandas as pd
from sklearn.feature_extraction.text import CountVectorizer

# Function to compute frequencies and n-grams
def analyze_words(word_list):
    vectorizer = CountVectorizer(ngram_range=(1, 2), token_pattern=r'\b\w+\b')
    X = vectorizer.fit_transform(word_list)
    frequencies = pd.DataFrame(X.toarray(), columns=vectorizer.get_feature_names_out())
    return frequencies

# Example usage
words = ['exemplo', 'palavra', 'análise']
print(analyze_words(words))
```
